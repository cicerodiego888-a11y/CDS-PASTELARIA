# MBC-13 — Checklist de produção

Produção só pode ser habilitada se **todos** os itens abaixo estiverem comprovados.

- [ ] provider oficial
- [ ] instituição definida
- [ ] documentação oficial
- [ ] endpoint oficial
- [ ] ambiente de produção
- [ ] autenticação validada
- [ ] OAuth validado
- [ ] callback validado
- [ ] certificado validado, quando aplicável
- [ ] SecretStore de produção
- [ ] conta real
- [ ] saldo real
- [ ] extrato real
- [ ] paginação validada
- [ ] cursor validado
- [ ] idempotência validada
- [ ] retry validado
- [ ] rate limit conhecido
- [ ] erros mapeados
- [ ] logs sanitizados
- [ ] multiempresa validado
- [ ] operação assistida concluída
- [ ] rollback definido
- [ ] aprovação final

Qualquer item ausente: **PRODUÇÃO BLOQUEADA.**

Situação atual: **PRODUÇÃO BLOQUEADA.**
